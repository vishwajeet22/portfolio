# portfolio
An AI powered portfolio for Vishwajeet Singh Thakur

# Vision/Desired features

- A minimalistic UI that shows a timeline style navigation at top
- A profile picture as the right sidebar, rounded with solar system type look
- A large name heading at the top left as the Logo/branding
- At the center a display container that shows the streaming output of the agentic backend
- A chat input box at the bottom
- The website should load fast and responsive on all devices, timeline navigation becomes vertical on mobile
- The look should be premium and minimalistic
- The navigation menu adapts as per the user
- The website feels the user emotions by tracking their interactions with the web, e.g. scrolling fast means in rush, stuck on a specific section means confused
- Agentic backend will be developed in python
- Website frontend should be static or built using some minimal react/next framework
- The website will be deployed on GCP, using cloud run - the agent does not need any memory
- A chatting 2D avatar on the website to answer questions about the projects
- The content of the website adapts automatically as per how the user identifies themselves, e.g. if the user identifies as a recruiter, the content should be tailored to that
- Content is cuarted in the preferred language of the user
- At the landing page of the website there should be a prompt to select the type of user (are they recruiter or investor or student or someone else) and the language, and based on that the content should be displayed
- The content of the portfolio will come from the AI agents dynamically, agents will also be a part of this project only.
- Source of the content will be the markdown files in the content folder, which will be curated by the AI agents.

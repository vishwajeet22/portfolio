## Key Projects at Arcesium (2017–2025)

### Event-Driven Real-Time Position Computation  
- **What it is:** A high-throughput system for computing and maintaining intraday trading positions in real time across all trades executed during the day.  
- **Impact:** Position computation is inherently resource-intensive, as traditional approaches require replaying the entire day’s data for every new trade. At the same time, trades are booked at extremely high frequency, making real-time computation non-trivial. I designed and implemented an event-driven, delta-based architecture that enabled real-time position updates without compromising trade booking resilience or throughput. This system became a core product offering at Arcesium.  
- **Tech Stack:** Java, AWS SNS/SQS, PostgreSQL  
- **Key Learnings:** Large-scale system design, event-driven architectures, and building highly decoupled yet resilient systems using SNS/SQS. Deep understanding of consistency, fault tolerance, and performance trade-offs in financial systems.  
- **My Role:** Designed key architectural components, led and mentored a team of developers through implementation, planned execution milestones, and conducted rigorous code reviews to ensure correctness and scalability.

---

### Calendar Infrastructure  
- **What it is:** Financial institutions use highly customized settlement calendars based on instruments, geographies, regulatory requirements, and internal policies, making standard calendars unusable. I led a multi-year initiative to replace a legacy calendar infrastructure (Perl, C++, JSP) with a modular, modern, and extensible calendar platform.  
- **Impact:** The new system reduced operational overhead by more than 75% and delivered over **$65K in annual infrastructure cost savings**, while significantly improving maintainability, extensibility, and developer velocity.  
- **Tech Stack:** Java, React, C++, Python, Docker, Kubernetes  
- **Key Learnings:** Modernizing legacy systems at scale, architectural simplification, and cost optimization. Learned that optimizing container images, eliminating unnecessary sidecars, and simplifying deployment architecture can result in disproportionately large infrastructure savings.  
- **My Role:** Evaluated and selected the modern technology stack, designed core components, led development efforts with hands-on coding, and enforced quality through structured code reviews.

---

### Zero-Touch Frameworks  
- **What it is:** A suite of configurable, zero-touch processing frameworks including offline anomaly reporting and start-of-day reporting systems. These frameworks were designed to support diverse client requirements with minimal manual intervention.  
- **Impact:** Replaced hours of repetitive manual work performed by analysts, significantly simplified new client onboarding, and enabled fully configurable, scalable reporting and alerting pipelines for complex operational workflows.  
- **Tech Stack:** Python, SQL Server, Batch Processing Systems  
- **Key Learnings:** Designing configurable systems, breaking complex data processing pipelines into reusable, composable stages, and stitching them together into flexible, extensible frameworks.  
- **My Role:** Low-level system design and end-to-end implementation of core framework components.
